# デバッグモード（ノータッチ稼働の記録）

既定は無効。無効のあいだは何も記録せず、本番と同じファイルのまま動く。

## 使い方

1. `index.html` を開き「デバッグ」を押す（`?debug=1` が付いて読み込み直す）
2. 「モニター1（L）を開く」「モニター2（R）を開く」で表示ページを開く（`?debug=1` が自動で付く）
3. 各画面をクリックして全画面にする
4. 「開始」を押して放置する
5. 終わったら control の「ログを保存」でテキストを書き出す

解除は「デバッグ中」をもう一度押す。ログは control の画面下に流れる。
記録はブラウザ内（localStorage）に残るので、途中で落ちても開き直せば取り出せる。

稼働中は control のウィンドウを最小化しない。最小化するとブラウザが時計を鈍らせる。

## 保存したテキストの読み方

先頭に期間・件数・各画面の最終生存時刻、次に「異常・注意」だけを抜いた一覧、最後に全記録が並ぶ。
まず「異常・注意」だけを見る。

| 記録 | 重み | 意味 |
|---|---|---|
| 落ちた形跡 | ! | 前回が正常に閉じずに終わった。落ちた時刻とそのときの表示項目が出る |
| 無応答 / 点呼なし | ! | 表示ページから返事が無い（クラッシュ・固まり） |
| 黒 | ! ? | 表示が1枚も無い時間があった（ミリ秒） |
| 真っ黒 | ! | 実際に描かれている絵が1.5秒以上まっ黒 |
| 重なり | ! ? | 2枚以上が同時に表示されたまま戻らない |
| 止まった / 進まない | ! | 再生位置が進まない |
| 巻き戻り | ! | 途中で頭出しし直された |
| 絵が固まる | ? | 再生位置は進むのに絵が2秒変わらない |
| 表示できず | ! | 指示した項目が5秒経っても出ない |
| 準備待ち切れ | ! | 読み込みが間に合わないまま切替時刻が来た |
| 取得 | . ? ! | 動画1本を fetch で取り切るのにかかった時間（10秒超で注意、20秒超で異常） |
| 取得失敗 | ! | 動画の fetch に失敗した（この項目は表示されない） |
| 左右差 | ! ? | L と R の再生位置の差（25ms超で注意、60ms超で異常） |
| 音 | ! ? | 音の予約が切替時刻からずれた／予約が間に合わなかった |
| 切替 | ? | 切替時刻からのずれ |
| lag | ! ? | ページの時計が飛んだ（固まり・スリープ・重い処理） |
| jsエラー / 未処理 | ! | 例外 |
| 連発 | ! | 同じ記録が10秒に25件を超えたので以降を伏せた |
| 60秒 | . | 1分ごとの生存記録（累積の時計ずれ・メモリ・ログ量） |

`累積ms` は音の時計と壁時計の開き。7時間かけてここが増え続ける場合、音と映像が
ゆっくりずれる。数百ミリ秒を超えるようなら音の予約方法を見直す。

## 構成

- `debug/sd_debug.js` … 記録係。3ページとも読み込む。役割はファイル名から判定する
- `index.html` … 切替・音・左右差・生死を記録し、画面下のパネルと保存ボタンを持つ
- `display_L/R.html` … 表示だけを見張る。10秒ごとの点呼に再生位置を返す
